v1 单文件已按方案改造为 **Vite + TypeScript + 原生 Three.js** 工程，三大 v2 功能全部落地，浏览器手测 5/5 通过、**26 项单测全绿**、`tsc --noEmit` 0 error、构建成功（bundle gzip ~143KB，运行时零 CDN）：

2. **天气系统**：晴/多云/雨/雪——云量平面（程序化 fBm alphaMap）、光照/雾/曝光倍率、雨天雨丝粒子 + 地面湿反光（roughness 0.35）、雪天积雪渐显
3. **相机运镜**：换季 2.2s easeInOut 方位角滑移 60°；自动巡游 0.05 rad/s，拖拽暂停 5s 恢复
4. **工程化与优化**：10 个场景系统模块化（含半球光 `systems/hemisphere.ts`）+ 4 个纯函数核心（26 项 vitest 单测覆盖）、零分配帧循环、envMap 脏标记节流、自适应 DPR（同时作用于后处理链）、几何体共享、依赖精确固定版本

架构细节见 [AGENTS.md](../AGENTS.md)。以下为 v1 时期的设计决策记录，参数表已连续化为轨道（见 `src/data/seasons.ts`）。

## 1. 项目概述

### 1.1 背景

探索"数据驱动 + 写实 PBR 光照"的浏览器端 3D 场景方案：以一座带室内灯光的房子为主体，验证时间与季节两个正交维度组合下，光照、大气、材质、粒子的系统性联动表现。

### 1.2 目标

- 交付形态（v2 已变更）：`npm run build` → `dist/` 静态站点，Three.js 打包进 bundle，运行期零 CDN
- 写实感光照：物理光照 + ACES 色调映射，天空-反射-雾全链路联动
- 12 种可切换的光照情绪，切换平滑过渡（~1.5s）
- 稳定 60fps（1080p 桌面端）

### 1.3 记忆点

**暮色冷调里，透射玻璃窗溢出的暖黄灯光** —— 冷暖对比是全部 12 种情绪的共同视觉锚点：室内灯 `~2700K` 暖黄与环境冷调（晨雾蓝 / 暮紫 / 雪夜深蓝）形成对抗，配合 Bloom 辉光形成"雪夜暖窗"式的画面焦点。

## 2. 需求范围

### 2.1 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| F1 | 房屋场景 | 双坡屋顶小屋：真实门洞/窗洞、烟囱、门廊小径、室内地板/木桌/吊灯 |
| F2 | 室内灯光 | 暖黄点光 + 灯泡自发光 + 窗玻璃透光，亮度三态（熄灭/待机/点亮） |
| F3 | 时间系统 | 早 / 中 / 晚 三档，驱动太阳轨迹、色温、雾、曝光 |
| F4 | 季节系统 | 春 / 夏 / 秋 / 冬 四档，驱动植被、积雪、大气、粒子 |
| F5 | 情绪组合 | 3 × 4 = 12 组参数化光照情绪，任意正交切换 |
| F6 | 过渡动画 | 全参数 1.5s 指数缓动（数值 lerp / 颜色 lerp） |
| F7 | 季节粒子 | 春樱瓣 / 夏萤火（仅夜）/ 秋落叶 / 冬雪，一套系统四态复用 |
| F8 | 交互 HUD | 底部玻璃拟态双选项卡 + 当前情绪读出 |
| F9 | 视角控制 | OrbitControls：拖拽旋转、滚轮缩放，限制俯仰与距离 |

### 2.2 非功能需求

- **性能**：1080p / 60fps 桌面端；三角面 < 15 万；单阴影光源；后处理 ≤ 3 pass
- **交付形态**：`dist/` 静态产物（base `./`，任意静态托管可用）；Three.js r160 随 bundle 打包，运行期无外部请求
- **零外部资产**：全部贴图 Canvas 程序化生成，无图片/模型文件
- **可维护**：视觉参数唯一数据源（MOODS 表），改观感不动系统

## 3. 美术方向

写实 PBR 风格：

- 材质全部 `MeshStandardMaterial` / `MeshPhysicalMaterial`，贴图含固有色/粗糙度语义
- 物理光照单位思维调参，`ACESFilmicToneMapping` + 每情绪独立曝光
- 写实感核心在**环境光**而非灯数量：天空大气散射实时烘环境贴图，反射随太阳连续变化
- HUD 反向克制：深色玻璃拟态 + 白字极简，避免 UI 抢画面

## 4. 总体架构

### 4.1 数据流

```
HUD 选项卡（时间×季节，正交）
   ↓
情绪参数表 MOODS（12 组 JSON，唯一数据源）
   ↓
过渡插值器（cur → target，指数缓动 k = 1 - e^(-2.4·dt)，颜色 THREE.Color.lerp）
   ↓
场景子系统（每帧读取插值后的状态）
   ├─ 天空系统   Sky shader（turbidity/rayleigh/mie + sunPosition）
   ├─ 太阳系统   DirectionalLight（位置 = 球坐标(仰角,方位)×45，2048 PCFSoft 软阴影）
   ├─ 环境烘焙   PMREMGenerator.fromScene(sky) → scene.environment（过渡期 0.38s 节流，落定补烘一次）
   ├─ 环境光     HemisphereLight（天空色 + 地面反弹色）
   ├─ 室内灯     PointLight(0xffc97e) + 灯泡 emissive + 玻璃 emissive 三者同联动
   ├─ 雾         FogExp2（颜色与天空地平线色同步）
   ├─ 色调映射   ACES 曝光系数随情绪变化
   ├─ 后处理     RenderPass → UnrealBloomPass(strength 随情绪) → OutputPass
   ├─ 季节视觉   树冠颜色/缩放、地面 tint、地面+屋顶积雪 opacity
   └─ 粒子系统   Points 单系统四模式（换色/尺寸/数量/混合模式/运动行为）
```

### 4.2 模块职责边界

| 模块 | 职责 | 禁止 |
|---|---|---|
| `MOODS` | 定义任意时刻的完整视觉状态 | 不含逻辑 |
| `lerpState` / `settled` | 插值与落定检测（自动遍历 NUM_KEYS/COL_KEYS） | 不感知具体系统 |
| `applyState` | 把状态写入各系统 | 不做决策、不存状态 |
| 各子系统 | 纯执行 | 不反向修改状态 |

新增视觉参数的标准路径：`MOODS` 加字段 → 同步维护 `NUM_KEYS`（数值）/`COL_KEYS`（颜色）→ `applyState` 写入目标属性。插值与落定检测自动生效。

## 5. 光照情绪矩阵（12 组参数设计）

设计原则：太阳仰角随季节整体下移（冬 < 秋 < 春 < 夏）；冬季雾最重、昼最短（晨晚均亮灯）；室内灯规则 = 日落后常亮 + 冬季昼短加码 + 正午仅冬季待机。

| 组合 | 氛围 | 太阳仰角/方位 | 太阳色 | 环境光（天空/地面） | 雾 | 曝光 | 室内灯 | 粒子 |
|---|---|---|---|---|---|---|---|---|
| 春·早 | 晨雾未散，新绿初生 | 15°/115° | 暖白 | 冷蓝/新绿 0.50 | 0.014 | 0.85 | 熄灭 | 樱瓣 |
| 春·中 | 光线明亮，草地嫩绿 | 60°/0° | 明亮白 | 湛蓝/嫩绿 0.75 | 0.004 | 1.00 | 熄灭 | 樱瓣 |
| 春·晚 | 暮色微凉，灯映晚霞 | 8°/-115° | 橙红 | 冷紫/深绿 0.35 | 0.016 | 0.75 | 点亮 | 樱瓣 |
| 夏·早 | 朝阳金亮，草木正盛 | 20°/115° | 金色 | 亮蓝/浓绿 0.60 | 0.006 | 0.95 | 熄灭 | 萤火(灭) |
| 夏·中 | 烈日当空，影子最短 | 70°/0° | 炽白 | 深蓝/深绿 0.85 | 0.002 | 1.05 | 熄灭 | 萤火(灭) |
| 夏·晚 | 火烧云下，虫鸣渐起 | 10°/-115° | 橘红 | 靛蓝/暗绿 0.30 | 0.012 | 0.70 | 点亮 | 萤火(亮) |
| 秋·早 | 薄雾金黄，落叶满地 | 12°/115° | 琥珀 | 灰蓝/金黄 0.45 | 0.018 | 0.80 | 熄灭 | 落叶 |
| 秋·中 | 天高云淡，层林尽染 | 50°/0° | 暖白 | 灰白/橙褐 0.60 | 0.008 | 0.95 | 熄灭 | 落叶 |
| 秋·晚 | 暮色四合，屋内亮灯 | 7°/-115° | 深橙 | 紫灰/褐橙 0.30 | 0.020 | 0.72 | 点亮 | 落叶 |
| 冬·早 | 天亮得晚，屋里已亮灯 | 8°/125° | 苍白 | 铅灰/雪白 0.42 | 0.028 | 0.80 | 点亮 | 雪 |
| 冬·中 | 日头很低，雪光清冷 | 35°/0° | 惨白 | 青灰/雪白 0.58 | 0.020 | 0.90 | 待机 | 雪 |
| 冬·晚 | 早夜里的大雪与暖窗 | 1°/-115° | 余晖 | 墨蓝/蓝雪 0.24 | 0.030 | 0.65 | 点亮 | 雪 |

其余字段（rayleigh、bloom、foliage、ground、snow、ffGlow 等）见源码 `MOODS` 表，与上表一一对应。

## 6. 渲染技术方案

| 专题 | 方案 | 理由 |
|---|---|---|
| 天空 | `Sky` 大气散射 shader，按太阳仰角实时渲染 | 连续、真实，天然支持晨昏色彩 |
| 环境反射 | `PMREMGenerator.fromScene(sky)` 烘 `scene.environment` | 反射随太阳连续变化；过渡期 0.38s 节流 + 落定补烘，控制开销 |
| 灯光 | 平行光（太阳）+ 半球光（反弹）+ 点光（室内灯） | 三层覆盖直射/环境/局部；仅太阳投影 |
| 玻璃 | `MeshPhysicalMaterial { transmission: 0.92, ior: 1.45 }` | 真透射，暖光穿窗溢出，配合 Bloom 形成记忆点 |
| 后处理 | RenderPass → UnrealBloomPass → OutputPass | Bloom 阈值 0.85 只取高光（灯泡/太阳/雪面泛光） |
| 贴图 | Canvas 程序化（灰泥/木板/瓦片/草地/树皮/精灵） | 零外部资产；地面贴图近中性灰，颜色由材质 tint 随季节变 |
| 色调 | ACESFilmic + 每情绪曝光（0.65 夜 ～ 1.05 夏正午） | 高光不死白、暗部有层次 |

## 7. 交互设计

- **双选项卡正交**：时间（早/中/晚）与季节（春/夏/秋/冬）独立选择，组合即情绪，符合"矩阵"心智模型
- **HUD 形态**：底部居中悬浮，`backdrop-filter: blur(16px)` 玻璃拟态、半透明深底、白字；选中态反白高亮
- **情绪读出**：面板顶部实时显示"秋 · 晚 — 暮色四合，屋内亮灯"，强化情绪叙事
- **过渡策略**：指数缓动天然抗连点抖动（无需硬锁 UI）；环境贴图节流刷新隐藏在过渡动画内
- **视角**：OrbitControls 阻尼旋转，俯仰限制 < 地平线，距离 5–26，禁平移防迷路

## 8. 季节系统规则

| 维度 | 春 | 夏 | 秋 | 冬 |
|---|---|---|---|---|
| 树冠 | 嫩绿→新绿 | 浓绿 | 金黄→橙褐 | 落叶（树冠组缩放至 0） |
| 树形 | 混植针叶（多层圆锥冠）与阔叶（有机球冠），共 6 株，形态由种子确定性生成 | 同左 | 同左 | 同左（仅剩树干与细枝） |
| 地面 | 草绿 | 深绿 | 褐橙落叶色 | 积雪白 |
| 积雪 | 无 | 无 | 无 | 地面 + 屋顶渐显 |
| 粒子 | 樱瓣（慢飘+侧摆） | 萤火（漂浮游走+加法混合发光，仅夜） | 落叶（快落+大幅横摆） | 雪（匀速直落+微摆，量最大） |
| 大气 | rayleigh 中 | 低（清澈） | 中高 | 高 + 雾最重 |

## 9. 性能预算与实测约束

| 项目 | 预算 | 实现手段 |
|---|---|---|
| 帧率 | 60fps @ 1080p | DPR clamp 2；单阴影光源；贴图启动期一次生成 |
| 阴影 | 2048 PCFSoft 单张 | 室内点光不投影 |

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 依赖版本漂移 | 渲染行为变化 | 依赖全部精确固定（无 `^`/`~`），Three.js 随 bundle 打包，无 CDN 依赖 |
| 透射玻璃开销 | 低端机掉帧 | 仅 2 块小面积玻璃；必要时降级为 opacity 半透明 |
| 环境贴图刷新 | 过渡期 GPU 尖峰 | 0.38s 节流 + 落定后仅补烘一次 |
| 色调映射调参 | 情绪间观感不一致 | 曝光进 MOODS 表逐组校准，禁止系统内硬编码补偿 |
| 连点切换 | 状态抖动 | 指数缓动天然收敛，无需锁 UI |
