| 维度 | 选择 | 含义 |

## 2. 材质体系：程序化 PBR 三通道

`src/systems/textures.ts` 整体重写为"高度图 → 法线 + 粗糙度"的生成管线：

- `makeRand(seed)`：LCG 确定性随机，保证每次构建贴图一致（截图可比对）。
- `normalFromHeight(height, strength)`：Sobel 环绕采样求梯度，输出切线空间法线（`nx=-du, ny=-dv`），比"直接画法线"更可控。
- `makeSurface({ size, repeat, relief, albedo, height, rough })`：一次生成 albedo（sRGB）+ normalMap + roughnessMap（线性）。
- `tileSurface(src, rx, ry)`：克隆三张图并改 repeat，让同一套表面按"实际米数"铺到不同尺寸构件上。

| 表面 | 尺寸 | 特征 | 用途 |
| --- | --- | --- | --- |
| concrete | 512 | 横向模板缝 + 对拉螺栓孔 + 云斑 + 气孔 | 一层体量、女儿墙、雨棚 |
| wood | 256 | 6 块竖板 + 板缝 + 顺纹 | 二层木饰面、室内地板（tint 不同） |
| deck | 256 | 5 块横板 | 露台 |
| metal | 128 | 横向拉丝 | 窗框、栏杆、压顶 |
| paving | 256 | 2×2 大石板 + 缝 | 入口铺装、庭院石板路 |
| gravel | 256 | 2600 颗卵石 | 山墙排水带 |
| grass | 512 | 9000 根草叶细纹 + 大块斑 | 地形底层 |
| snow | 128 | 柔和起伏 | 屋顶积雪、地面积雪 |
| leaf | 256 | 90 片椭圆叶（alpha） | 树冠叶卡、灌木 |
| bark | 128 | 竖向深沟 | 树干、柴堆 |
| cloud | 512 | 多层径向渐变 fBm | 云层 |

## 3. 建筑：`src/systems/house.ts` 整体重写

世界坐标（米），正面 +z，主体 9×7 居中于原点，层高 3.1，屋面板 0.35。

- **一层**：清水混凝土体量 + 基座；后墙高窗带、左右山墙横向/高窗、正立面竖窗缝；入口内凹（两侧混凝土夹壁）配木门与金属拉手；paving 地坪 + 两级混凝土台阶。
- **幕墙**：正立面 8.75×3.1 落地玻璃（5 竖梃 / 4 横梃）+ 4.0m 转角玻璃，室内可透视。
- **二层**：悬挑楼板（正 1.1 / 侧 0.2），木饰面体量与 8.9m 长窗，17 根 0.07×2.88×0.20 竖向木格栅遮阳。
- **屋顶**：平屋面板 + 四周女儿墙 0.62 + 金属压顶外挑 0.05；屋面与女儿墙顶有积雪面；两处线性灯槽。
- **露台**：木 platform（x[-0.05,4.75] z[3.65,6.10]，台面 y=0.28）+ 0.025 方钢细栏杆（前 42 根 / 侧 22 根 / 扶手 1.28）。
- **雨棚**：y 3.24~3.40 混凝土挑板，两端锚进内凹侧壁，无悬空。
- 全部按材质合并为 8 个 Mesh（concrete / wood / deck / metal / paving / glass / snow / lamp），贴图经 `tileSurface` 按平米换算。
- **室内背衬壳**：墙体是单面盒体（渲染时背面剔除），没有内表面，透过玻璃会直接看到天空，窗户在白天是一片"死白"；因此在墙内侧加两个 `side: BackSide` 的盒体（一层 + 二层各一），从室外透过玻璃看到的是壳的内表面，窗内立刻有了暗部与景深。
- **幕墙玻璃**：`transmission 0.18`（只做轻微折射）、`thickness 0.02`（0.4 的屏幕空间采样偏移会糊成乳白磨砂）、`opacity 0.13`、`envMapIntensity 0.5`（1.6 时整片幕墙反射亮天空，看起来像白板）、`roughness 0.05`、`transparent + depthWrite:false`。

`HouseMats = { glassMat, roofSnowMat, pathMat, lampMat, metalMat, concreteMat, floorMat, woodMat }`（前六个是跨系统契约，后两个供 interior 复用）。

## 4. 室内：`src/systems/interior.ts`

地板 / 地毯 / 沙发 / 茶几 / 餐桌椅 / 吊灯 / 厨房柜体与岛台 / 落地灯 / 顶棚灯槽；4 盏 PointLight（主厅、起居、二层、外溢），`apply` 只读 `params.lamp` 写 intensity 与 `lampMat.emissiveIntensity`，零分配。

## 5. 植被与庭院

- **植被**（`vegetation.ts`）：近景 6 株（3 针叶 7 层 22 段开口锥冠——层间交叠 1/3、底缘下垂、每层微倾 ±0.07rad；3 阔叶 10 段分枝），六株距原点均 ≥10.48m（避免挡住建筑）；树干 bark PBR 合并 2 drawcall；树冠为交叉叶卡 + `alphaTest 0.5` + RGBA 深度打包的 `customDepthMaterial`（投影不是方块）；冬季树冠与灌木随 `folScale` 收缩隐藏；远景树线 34 株「落地短干 + 3 层开口锥」合并 1 个 Mesh（高 8~13m、半径 60~110m、雾色混合 0.3）。
- **庭院**（`garden.ts`）：InstancedMesh 草坪（14000 丛，单实例 3 片 60° 草叶，单叶宽 12~16mm、高 10~15cm，顶点色根暗尖亮）、3 块花境 300 株（花瓣/花心/茎）、44 块石材（小径 30 块 + 花圃石缘 + 灯座）、2 盏 0.69m 矮灯柱、山墙柴堆；播撒规避建筑/露台/台阶/小径/雨棚投影；`count` 随 `grassLevel` / `bloomLevel` 变化，雪天草色向白 lerp 并压成 4.5cm 残茬。

## 6. 光照、天空与后处理

- 天空：Sky 大气散射调成写实向（turbidity 3.4 / mieCoefficient 0.0035 / mieDirectionalG 0.83），保留脏标记 + 节流 + 落定补烘。
- 后处理链：RenderPass → SSAOPass → UnrealBloomPass → OutputPass → SMAAPass；SSAO 参数 `kernelRadius 0.42 / minDistance 0.0018 / maxDistance 0.06`。
- 地形：340m 平面 128 细分，26m 内平坦、之外用两层确定性噪声起伏（最高 7.5m），远山仅做天际线；雾密度下限 `FOG_MIN_DENSITY` 保证地平线不露硬边。
- 相机：FOV 38（长焦建筑摄影观感），默认机位与目标来自 `config.ts`；换季扫视角度从 60° 收到 18°，转完仍保持建筑主构图。

## 12. 加载页（刷新首帧，2026-10-20）

刷新瞬间会先看到"未上样"的原始 HTML：品牌字、系统灰按钮、左上一行「正在构建场景 …」。根因是全部样式都由 `src/main.ts:1 import './ui/style.css'` 注入，要等 JS 模块图（three.js 等）下载执行后才生效。

做法：**加载页样式内联在 `index.html` 的 `<style>` 里**（关键 CSS，不经过打包器），并给 `<html>` 加 `class="boot"`；`html.boot #brand, html.boot #hud` 在加载期间 `opacity:0; visibility:hidden`，`main.ts` 首帧渲染完成后 `rootEl.classList.remove('boot')` 一并显形。`src/ui/style.css` 不再有 `#loader` 规则（外部样式表后加载会覆盖内联样式）。

- 视觉：radial-gradient 夜景底 → 竖排「四时之屋」32px/.34em + HOUSE OF SEASONS 11px/.42em → 44px 渐变细线 → 168×2px 进度条（暖金 #d9b07a 光带 1.35s 循环）→「正在构建场景」；底部提示「拖拽旋转 · 滚轮缩放」。
- 无障碍：`role="status" aria-live="polite" aria-busy="true"`，完成时置 `aria-busy=false` 并在 900ms 淡出后移除节点；`prefers-reduced-motion` 关动画；`<noscript>` 提示需要 JavaScript / WebGL。
- 失败兜底：`createRenderer()` try/catch（不支持 WebGL 2）、`window.addEventListener('error', …, { once: true })` → `bootFail()` 把进度条转 #b4553f 并换成可读文案，避免永远转圈。

验证方式：CDP `Network.setBlockedURLs(['*/assets/*.js', '*.js'])` 拦掉 JS，模拟"脚本还没到"的首帧截图（`.screenshots/boot-04.png`）——只有加载页，没有未上样的控件。
