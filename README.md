# 四时之屋 · House of Seasons

**v2 工程化版本** — Vite + TypeScript + Three.js 写实光照 3D 场景：一座亮着暖灯的小屋，支持 **0–24h 连续时间 × 四季 × 四种天气**，选项卡与滑杆一键切换，1.5s 平滑过渡，换季自动运镜。

> 记忆点画面：暮色冷调里，透射玻璃窗溢出的暖黄灯光 —— "雪夜暖窗"。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
```

其他命令：

| 命令 | 说明 |
|---|---|
| `npm run test` | Vitest 单元测试（太阳几何/轨道插值/灯光规则/昼夜开关/参数自洽） |
| `npm run lint` | ESLint 检查 |
| `npm run build` | 类型检查 + 生产构建 → `dist/` |
| `npm run preview` | 预览生产构建 |

Three.js 已打包进 bundle，运行时**零 CDN 依赖**；`vite.config.ts` 的 `base: './'` 使 `dist/` 可部署到任意静态托管（IGA Pages：项目根目录执行 `iga pages deploy`）。

## 操作说明

| 操作 | 效果 |
|---|---|
| 拖拽 / 滚轮 | 旋转 / 缩放视角 |
| 时刻滑杆 | 0–24h 连续太阳轨迹（日出日落随季节变化） |
| 早 / 中 / 晚 | 吸附到 7:30 / 12:30 / 18:30 |
| 季节选项卡 | 春 / 夏 / 秋 / 冬（切换触发 2.2s 运镜滑移） |
| 天气选项卡 | 晴 / 多云 / 雨 / 雪 |
| 巡游按钮 | 自动环绕（拖拽暂停 5s 后恢复） |

读出行实时显示 `季节 · hh:mm · 天气`。

## 核心机制

```
HUD（滑杆/季节/天气）→ TimeState{ hour, season, weather }
    → resolveParams（核心：四季关键帧轨道插值 ⊕ 太阳几何 ⊕ 天气修饰 ⊕ 派生量）
    → 指数缓动（~1.5s，数值/颜色 lerp，零分配）
    → 各系统 apply()：天空·太阳·半球光·室内灯·植被·地面·云层·粒子
    → 渲染管线（物理光照 · Sky+PMREM 环境反射 · ACES · Bloom）
```

- **连续时间**：太阳仰角按季节日出/日落表（春 6-18h、夏 5.5-19h、秋 6.5-17.5h、冬 7.5-17h）走正弦弧线；方位角按昼长归一（日出恒 115°、正午 0°、日落 -115°）；直射光强度乘 `daylight(elev)`（地平线下归零）；所有视觉参数按「夜/深夜/晨/午/暮」五锚点轨道随时刻插值
- **室内灯**：太阳仰角 >4° 灭、<-3° 亮，之间 smoothstep 渐变
- **天气**：云量/光照倍率/雾倍率/曝光倍率/地面湿滑五维修饰；雨天雨丝粒子 + 地面反光；雪天积雪渐显
- **季节粒子**：春樱瓣 / 夏萤火（夜+晴）/ 秋落叶 / 冬雪；雨天雪天覆盖季节粒子
- **性能**：单阴影光源 2048 PCFSoft、envMap 脏标记节流重烘、自适应 DPR（持续掉帧自动降采样，同步后处理链）、几何体共享、粒子 ≤ 540

## 目录结构

```
src/data/        季节轨道表 + 天气修饰表（视觉参数唯一数据源）
src/core/        纯函数：状态解析/插值/太阳几何/主循环（可单测）
src/systems/     场景系统：sky/sun/hemisphere/interior/house/vegetation/environment/particles/weather/camera
src/ui/          HUD 绑定与样式
tests/           Vitest 单元测试
docs/项目方案.md  设计方案与 v2 实施记录
AGENTS.md        编码代理协作约定
```

自定义观感：改 `src/data/seasons.ts` 的轨道锚点值即可，无需触碰渲染系统。
